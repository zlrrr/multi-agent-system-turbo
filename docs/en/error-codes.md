# Error-code reference

> Generated by `mas errcodes --format markdown --lang en`. Do not edit by hand.
> Bilingual pair: [`../zh/error-codes.md`](../zh/error-codes.md)

Every error crossing a boundary carries a stable `MAS-NNNN` code, allocated by domain
(Constitution Article V).

## Configuration and request

| Code | Severity | Symbol | Meaning | What to do |
|---|---|---|---|---|
| `MAS-1001` | error | `ConfigInvalid` | configuration file %q could not be parsed | Check the YAML syntax; run `mas doctor --config <path>` for a precise location. |
| `MAS-1002` | error | `ConfigUnknownField` | unknown configuration field %q | Remove the field or check docs/en/configuration.md for the correct name. |
| `MAS-1003` | error | `ConfigValidation` | configuration is invalid at %s: %s | Correct the named path; every constraint is listed in docs/en/configuration.md. |
| `MAS-1004` | error | `ConfigNotFound` | no configuration file found in %v | Pass --config, set MAS_CONFIG, or place mas.yaml in the working directory. |
| `MAS-1005` | error | `TargetUnknown` | unknown target %q | Run `mas targets` to list configured targets. |
| `MAS-1006` | error | `SecretUnresolvable` | secret reference %q could not be resolved | Ensure the referenced environment variable or file exists and is readable. |
| `MAS-1007` | error | `RequestInvalid` | diagnostic request is invalid: %s | Correct the request; `mas diagnose --help` documents every field. |
| `MAS-1008` | error | `EnvUnknown` | target %q references unknown environment %q | Declare the environment under `envs:` in the configuration file. |
| `MAS-1010` | error | `WindowInvalid` | invalid time window: %s | Use --since (e.g. 1h) or an explicit --from/--to pair with from < to. |
| `MAS-1011` | error | `ModeInvalid` | invalid mode %q | Use `offline` (telemetry only) or `online` (also reads the live environment). |
| `MAS-1012` | error | `TelemetrySourceUnknown` | unknown telemetry source %q | Declare the source under `telemetry.metrics` or `telemetry.logs`. |

## LLM providers

| Code | Severity | Symbol | Meaning | What to do |
|---|---|---|---|---|
| `MAS-2001` | error | `ProviderUnavailable` | LLM provider %q is unavailable | Check network reachability and base_url; the run continues with deterministic findings only. |
| `MAS-2002` | error | `ProviderAuthFailed` | LLM provider %q rejected the credentials | Verify llm.api_key and that the key has access to the requested model. |
| `MAS-2003` | error | `ProviderRateLimited` | LLM provider %q rate-limited the request | Retry later, lower run.budget, or use a model with higher quota. |
| `MAS-2004` | error | `ToolCallUnparseable` | model produced an unusable tool call for %q: %s | The agent retries with a repair prompt; persistent failures suggest a weaker model. |
| `MAS-2005` | error | `ProviderUnknown` | unknown LLM provider %q | Use one of: mock, anthropic, openai. |
| `MAS-2006` | warn | `ModelRefused` | model declined to answer: %s | Rephrase the symptom, or inspect the prompt with --log-level debug. |
| `MAS-2007` | warn | `TokenBudgetExceeded` | token budget exhausted after %d tokens | Raise run.budget.max_tokens, or accept the truncated analysis. |
| `MAS-2008` | error | `ProviderResponseMalformed` | LLM provider %q returned a malformed response: %s | Confirm base_url points at a compatible API; enable debug logging to inspect the body. |
| `MAS-2009` | error | `MockScriptExhausted` | mock provider script has no reply for turn %d | Extend the mock script; this only occurs in tests and demos. |
| `MAS-2010` | warn | `CitationUnresolved` | the model cited %d reference(s) that this run did not collect: %s | The unresolved references were dropped from the report. A model that cites evidence it was not given is guessing; check the transcript for the role that produced them. |

## Collectors, adapters and source

| Code | Severity | Symbol | Meaning | What to do |
|---|---|---|---|---|
| `MAS-4001` | error | `MetricsUnreachable` | metrics source %q is unreachable: %s | Check telemetry.metrics[].url and network policy; analysis continues without metrics. |
| `MAS-4002` | error | `MetricsStatus` | metrics source %q returned HTTP %d | Verify the endpoint path and credentials for the metrics source. |
| `MAS-4003` | error | `MetricsMalformed` | metrics source %q returned a malformed response: %s | Confirm the URL points at a Prometheus-compatible HTTP API v1. |
| `MAS-4004` | error | `MetricsQueryRejected` | metrics query rejected: %s | The PromQL was refused by the server; check the knowledge pack's signal definition. |
| `MAS-4005` | warn | `MetricsTruncated` | metrics result truncated at %d samples | Narrow the window or raise telemetry.metrics[].max_samples. |
| `MAS-4101` | error | `LogsUnreachable` | log source %q is unreachable: %s | Check telemetry.logs[].url; analysis continues without logs. |
| `MAS-4102` | error | `LogsStatus` | log source %q returned HTTP %d | Verify the endpoint path and credentials for the log source. |
| `MAS-4103` | error | `LogsMalformed` | log source %q returned a malformed response: %s | Confirm the URL points at a Loki-compatible HTTP API v1. |
| `MAS-4104` | error | `LogsQueryRejected` | log query rejected: %s | The LogQL was refused by the server; check the knowledge pack's log pattern. |
| `MAS-4105` | warn | `LogsTruncated` | log result truncated at %d lines | Narrow the window or raise telemetry.logs[].max_lines. |
| `MAS-4201` | warn | `KubeForbidden` | Kubernetes denied read access to %s: %s | Grant the service account `get`/`list` on that resource; the run continues with a gap. |
| `MAS-4202` | warn | `KubeNoCredentials` | no Kubernetes credentials available for environment %q | Set envs.<name>.kubeconfig, or run in-cluster with a service account. |
| `MAS-4203` | error | `KubeUnreachable` | Kubernetes API server is unreachable: %s | Check the server URL, CA bundle and network policy. |
| `MAS-4204` | warn | `KubeNotFound` | Kubernetes object not found: %s | Check the namespace and selector on the target definition. |
| `MAS-4205` | error | `KubeMalformed` | Kubernetes API returned a malformed response: %s | Confirm the URL points at a Kubernetes API server. |
| `MAS-4210` | warn | `KubeExecDisabled` | in-container execution is disabled for environment %q | Set `envs.<name>.exec: true` (or remove the key) to let the guard decide per command. The switch can only narrow: it never widens what the guard allows. |
| `MAS-4211` | error | `KubeExecPodNotInTarget` | pod %q is not an instance of target %q | Exec is bound to the instances the target resolved to, so a run can never reach a pod outside it. Check the target's selector. |
| `MAS-4212` | warn | `KubeExecUpgradeFailed` | could not open a remote-command stream to %s: %s | Usually RBAC: the credential needs `create` on `pods/exec`. It can also mean the pod is gone or an admission policy forbids exec. |
| `MAS-4213` | error | `KubeExecStreamMalformed` | the remote-command stream from %s was malformed: %s | The apiserver or an intermediary did not speak the v4.channel.k8s.io protocol. Check for a proxy that rewrites WebSocket traffic. |
| `MAS-4214` | warn | `KubeExecNoExitStatus` | the command in %s ended without reporting an exit status | The output is reported with its status recorded as unknown. It is not treated as success: a command whose outcome never arrived has not been shown to have worked. |
| `MAS-4301` | warn | `HostCommandFailed` | host command %q failed: %s | Check that the command exists and the process has permission to run it. |
| `MAS-4302` | warn | `HostBinaryNotFound` | binary %q not found on PATH | Install the tool in the image or on the host, or omit checks that need it. |
| `MAS-4303` | warn | `HostUnsupported` | host inspection %q is not supported on %s | This check is skipped; it is available on Linux hosts. |
| `MAS-4401` | warn | `SourceFellBackToMirror` | source for %q unreachable over the network; using local mirror %s | Expected in air-gapped environments; verify the mirror matches the deployed version. |
| `MAS-4402` | warn | `SourceUnavailable` | no source available for %q: %s | Configure source.repos or source.mirrors; source-based analysis is skipped. |
| `MAS-4403` | warn | `SourceRefNotFound` | source ref %q not found for %q | Check the target's version, or fetch the default branch instead. |
| `MAS-4404` | error | `SourceSearchInvalid` | source search pattern is invalid: %s | Use a valid RE2 regular expression. |
| `MAS-4405` | warn | `SourceToolMissing` | git is not available; source acquisition is disabled | Install git in the image or on the host to enable source-based analysis. |

## Knowledge packs and rules

| Code | Severity | Symbol | Meaning | What to do |
|---|---|---|---|---|
| `MAS-5001` | error | `PackSchemaViolation` | knowledge pack %s is invalid at %s: %s | Fix the pack against docs/en/knowledge-packs.md, then reload. |
| `MAS-5002` | error | `PackDuplicate` | duplicate knowledge pack id %q | Two packs under knowledge.pack_dirs claim the same id, so which one wins would depend on directory order. Rename one, or delete the copy you no longer use. Overriding a built-in pack is supported and is not this error. |
| `MAS-5003` | warn | `PackNotFound` | no knowledge pack for middleware %q | Add a pack under knowledge.pack_dirs; analysis proceeds with generic checks only. |
| `MAS-5004` | error | `PackVersionRangeInvalid` | knowledge pack %s has an invalid version range %q | Use a range such as ">=5.0", "<7", or ">=5.0 <8.0". |
| `MAS-5005` | error | `PackReadFailed` | knowledge pack %s could not be read: %s | Check file permissions on the pack directory. |
| `MAS-5010` | error | `ExpressionCompile` | playbook %s step %s has an invalid expression: %s | Fix the expression; only step results and helper functions are in scope. |
| `MAS-5011` | error | `ExpressionType` | playbook %s step %s expression did not evaluate to a boolean: %s | An `evaluate` expression must yield true or false. |
| `MAS-5012` | error | `SignalUnknown` | playbook %s references unknown signal %q | Declare the signal under `signals:` in the same knowledge pack. |
| `MAS-5013` | warn | `PlaybookBudgetExceeded` | playbook %s exceeded its step budget of %d | Split the playbook, or raise run.budget.max_steps. |
| `MAS-5014` | error | `PlaybookStepInvalid` | playbook %s step %s is invalid: %s | A step must declare exactly one of collect, evaluate or conclude. |
| `MAS-5015` | warn | `CheckNotPerformed` | playbook %s step %s was skipped: %s | The check had no data to read, so its failure mode is neither confirmed nor ruled out. Check that the signal exists in this deployment. |
