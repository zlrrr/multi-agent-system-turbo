# 实施计划：模型路由与如实的成本核算

> **特性 ID**：`005-model-routing-and-cost` · **版本**：1.0.0 · **状态**：已批准
> **双语对应文件**：[`plan.md`](./plan.md) · **上游**：[`spec.zh.md`](./spec.zh.md) v1.0.0 · **下游**：[`design-hld.zh.md`](./design-hld.zh.md)

## 1. 思路

两半在代码上都不大，在设计上却都很关键，因此本计划主要是在选形态。

**路由**变成一个解析器：给定本次运行的 LLM 配置与一个角色，
返回该角色所用的 provider **与**模型。今天的 `ModelFor` 已经做了其中一半；
把它扩展为同时返回 provider，能让按角色覆盖变得统一 ——
而不是"模型与温度可覆盖、provider 不可覆盖"这种没人记得住的不对称。

**成本**变成一个类型，而不是一个浮点数。`Usage.CostUSD float64` 无法表达"未知"，
于是每一个消费方都得记住 `> 0` 这个约定。带显式 `Known` 标志的 `Cost`
让"未知"不可能被误渲染 —— 而这正是本需求的全部。

## 2. 设计决策

| ID | 决策 | 理由 | 反转条件 |
|---|---|---|---|
| D-1 | 用 `Cost{USD float64; Known bool; Unpriced []string}` 取代裸浮点 | 浮点数没有办法说"未被测量"，于是每个渲染器都得记住一个约定。只要有一个渲染器粗心，就会为一次从未定价的运行打印 `$0.00`，而运维人员会信以为真 | — |
| D-2 | 价格是配置，且本项目不内置任何价目表 | 价格会变、随合同与区域而异，并且会悄无声息地过期。一个看起来权威却是错的数字，比一个被承认的缺口更糟（CON-002） | — |
| D-3 | 部分定价的运行既报告已定价部分，**也**点名未定价的模型 | 整体隐去会浪费真实信息；只给数字而不加限定则会低估这次运行。两半都在，这个数字才有意义 | — |
| D-4 | 路由解析到 provider **实例**，每次运行只打开一次 | 每次调用都开一个会成倍增加连接，并把凭据错误藏进运行过程中，而不是暴露在准入阶段 | — |
| D-5 | 按角色 provider 默认继承默认配置，除非显式覆盖 | 否则每个只想改一个字段的角色都得把端点、超时与密钥重述一遍 —— 而漏掉的那个字段会在最糟的时刻失败 | — |
| D-6 | 按角色的用量由计数包装器累加，并以角色为键 | 核算本来就集中在一处；给它加个键，比把总量穿过每个角色要小得多，而且不可能与它所计的调用发生漂移 | — |
| D-7 | `mas models` 是一个新的列表类命令，而不是 `mas config` 上的一个 flag | 生效路由是**推导**出来的，而不是配置出来的：它回答"实际会发生什么"，这与"我写了什么"是两个问题 | — |

## 3. 风险

| ID | 风险 | 缓解 |
|---|---|---|
| RSK-001 | `Cost` 类型变更牵动报告、存储与 API，漏改一处就会悄悄退回打印 0 | 浮点字段是被**移除**而非弃用，因此每一处都会编译失败直到被更新；并有测试断言任何渲染出的报告都不含 `$0.00` |
| RSK-002 | 运维人员把价格填错却相信总额 | 报告写明计价依据；文档说明价格由运维人员提供，该数字的可靠程度不会高于它们 |
| RSK-003 | 按角色 provider 让凭据在内存与日志中成倍出现 | 每一个都由同一个脱敏器在同一个边界处理；并有测试断言按角色的密钥绝不出现在步骤记录中 |
| RSK-004 | 并发拓扑下用量在角色之间错配 | 归属在本就保护计数器的那把锁内完成，并发测试在 `-race` 下运行 |
| RSK-005 | 路由让运行不可复现 | 运行记录携带生效路由，因此一次比较可以被完全重复（FR-012） |

## 4. 阶段

| 阶段 | 内容 | 闸门 |
|---|---|---|
| A | `Cost` 类型；更新所有消费方；未定价绝不渲染成数字 | 两种语言的报告测试；任何地方都不出现 `$0.00` |
| B | 定价配置；计算成本；点名部分定价 | FR-004、FR-005、FR-009 |
| C | 按角色 provider 路由；只打开一次；准入失败 | FR-001…FR-003、FR-012 |
| D | 按角色核算；报告与运行记录 | FR-007、FR-008、NFR-006 |
| E | `mas models`、doctor、双语文档 | `make ci`、`sddctl verify` |
