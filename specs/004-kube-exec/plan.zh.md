# 实施计划：在 Kubernetes Pod 内执行只读命令

> **特性 ID**：`004-kube-exec` · **版本**：1.0.0 · **状态**：已批准
> **双语对应文件**：[`plan.md`](./plan.md) · **上游**：[`spec.zh.md`](./spec.zh.md) v1.0.0 · **下游**：[`design-hld.zh.md`](./design-hld.zh.md)

## 1. 决定其余一切的那个决策

Kubernetes 客户端不能新增 `Exec` 方法，否则 `TestClientHasNoMutatingMethods` 会失败 ——
而这条测试不应被削弱：基于方法名的结构性检查无需评审者做任何判断，因此它不会腐化。

解法是**通过保留这个类型来保留这条不变量**。执行能力放进
**另一个文件里的另一个类型** `ExecClient`，它：

- 不持有 `Client` 的任何引用，且只暴露一个方法；
- 从 namespace、Pod 与容器自行拼出 URL —— 它不接受调用方传入的路径，
  因此在结构上就无法访问 exec 子资源以外的任何端点；
- 携带的是参数向量而非命令字符串，因此即便真有 shell 可达，也没有任何东西供其解释。

`Client` 的性质 —— "每个方法都发 GET，且没有一个方法能表达变更" —— 原封不动地保留；
而 `ExecClient` 获得了一条同样机械的自有性质：**一个方法、一种 URL 形态、没有路径参数**。
一条新的审计测试会断言后者，所以这次拆分不是"用一条已检查的不变量换一条未检查的"。

## 2. 设计决策

| ID | 决策 | 理由 | 反转条件 |
|---|---|---|---|
| D-1 | 执行能力放进独立的 `ExecClient`，而不是挂到 `Client` 上 | 让既有结构性审计原样通过，同时给 exec 一条同样机械的自有不变量 | — |
| D-2 | 采用 WebSocket（`v4.channel.k8s.io`）而非 SPDY | 早在本项目所面向的任何版本之前，apiserver 就已接受 WebSocket 远程命令；其帧格式不过是几百行 RFC 6455；而且它是"带升级的 GET"—— 因此护栏里根本不会引入新的 HTTP 动词。实现 SPDY 只会多出一套协议实现，却换不来任何新能力 | 目标 Kubernetes 版本早于 WebSocket exec —— 现存的受支持版本没有一个如此 |
| D-3 | 把 `ExecEffect` 做成一等效果，由护栏**同时**对照命令白名单与 exec 路径规则 | "在那个 Pod 里执行这条命令"是一个带两重约束的效果。拆成两次 `Authorize` 会把"如何组合"交到调用方手里，而漏掉一次的调用方照样能编译通过 | — |
| D-4 | `kubectl` 永久排除在白名单之外 | 一个二进制名会代表整个 Kubernetes API —— 这正是"默认拒绝"要防的失败，也正是 OceanBase 知识包至今不带 `obclient` 的同一条理由 | — |
| D-5 | Pod 必须来自已解析目标的实例集合 | 能指定任意 Pod 的 Agent，就能读取任意 Pod。把 exec 绑定到目标解析结果，可让影响半径与本次运行的其余部分保持一致 | — |
| D-6 | 不支持 stdin、不支持 TTY | 读取状态两者都不需要，而它们会把"一次性读取"变成一段可被提示词操纵的交互会话 | 当某个知识包确实需要交互式工具时 —— 目前没有 |
| D-7 | exec 默认开启，开关只能关闭 | 本地适配器早已在无需 opt-in 的情况下执行白名单命令，真正起作用的控制是护栏。一个只能收紧的开关，为受策略约束的运维人员提供了手段，又不会造出一个能放宽的口子 | — |

## 3. 风险

| ID | 风险 | 缓解 |
|---|---|---|
| RSK-001 | 手写的 WebSocket 客户端帧处理有误而挂起，把本次运行的超时一起拖没 | 上下文截止时间作用于连接本身而不仅是读循环；所有测试都在短超时下运行；畸形帧会变成带码的缺口 |
| RSK-002 | 通道解复用把 stderr 当成 stdout，或丢掉承载退出状态的 error 通道 | 测试服务端说的是真协议、并由服务端侧驱动，因此客户端绝不会只对着自己的假设受测（NFR-002） |
| RSK-003 | 运维人员因为"这是 exec"就认为它安全，进而要求放宽白名单 | 文档明说：本特性改变的是"受审核命令能在哪里执行"，绝不改变"哪些命令通过了审核" |
| RSK-004 | 输出淹没上下文窗口或报告 | 护栏字节上限生效，截断记为缺口，并明确告知读者被截掉了什么 |
| RSK-005 | 日后有人给 `ExecClient` 加了第二个方法，把面重新打开 | 新审计测试断言"只有一个方法"的形态，重新打开会让构建失败 |
